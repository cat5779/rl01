# DPP 小理论与连通性路线图

## 目标与判据

目标是抽离能反复使用的比较与构造原理，逐项证明应用。每个问题均按原作者最强合理含义审查；只对现有论证真正覆盖的量词作结论。未完成的接口保留为路线节点，不通过改名或弱化目标将其关闭。

| 节点 | 精确目标 | 依赖与现有证据 | 尚须完成的步骤 | 验收标准 |
|---|---|---|---|---|
| H | 给定可数作用与交换的 Hermitian 正压缩核，构造相应索引 iid 的等变 DPP 因子 | 冻结主证明已通过内部全文与对抗审查 | 必要领域外审、归属与查新；应用中的随机源须另核对 | 源空间、全输入等变性、可测性及目标分布均逐条闭合 |
| C | 任意可数群正则轨道上，每个 A≤B 存在不变单调 DPP 联合律 | 完整过程与逼近稿已有全文审查通过 | 交叉审查、定向回应关键缺口、领域外审与归属 | 覆盖一般核及奇异端点；不得用边缘不变性替代联合不变性 |
| D | 任意正压缩 A,B 的尖锐不变距离界 d̄≤τ(abs(A−B)) | C 加折线路径；反向也可由最小值取得推出 C | 合并量词和归一化陈述 | 明确只用不变联合律；常数一与源论文量词一致 |

| L | 一般无限有限生成群的 cost=1+β₁⁽²⁾ | H 可提供 Cayley FUSF 的 iid 编码；已有两份探索稿明确未完成 | 廉价连通修复或有预算的删边换边；原探索 RL01 PR #88–90 | 连通性及代价同时证明，区分群 cost、给定作用 cost 与 fixed price |

## 依赖顺序

- C 与 D 是同一正则轨道核类上的等价普遍断言；D 可由 C 的有限折线推出。
- F 与 O 构成原 FK 猜想的支配和逐核最优性两部分。F 的证明通过不能关闭 O。
- H+C 并未关闭 JO，H+F 并未关闭 JF。这两个箭头就是当前构造工作的目标。
- U 须给出一个真实的共同构造。即使 JF、JO 都成立，仍须说明共同机制及各自端点条件。
- H→FUSF 编码只完成 L 的随机源接口，不完成连通修复。原题若只要求群 cost 的下确界，不能把 Bernoulli 作用上的结论偷换为同一命题。

## 连通性子节点

1. **L1：无限接触的多尺度条件引理。** 已有可复核的条件证明；须证明目标 FUSF 满足其几何假设，或寻找反例。条件引理本身不关闭 L。
2. **L2：循环空间与删边换边。** 候选把多付出的边代价写成有限循环子模维数；其无限度图、测度关系同调和引用前提须独立核验。
3. **L3：近似与达到。** ε 级近似、精确达到、弱极限连通和关联边质量不逃逸分别审查；不能从紧致性直接继承连通性。

## 续接规则

新材料先挂到对应节点并保全原件，再审承重步骤；结果为不完整时记录精确缺口和可复用的局部结论。新的研究任务应关闭一个节点、证明严格更弱且有用的引理，或给出反例，不重复催问已有运行任务。领域外审与查新分别记账，不能由内部审查次数代替。
