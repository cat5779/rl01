# DPP 小理论与连通性路线图

## 目标与判据

目标是抽离能反复使用的比较与构造原理，逐项证明应用。每个问题均按原作者最强合理含义审查；只对现有论证真正覆盖的量词作结论。未完成的接口保留为路线节点，不通过改名或弱化目标将其关闭。

## 依赖顺序

- C 与 D 是同一正则轨道核类上的等价普遍断言；D 可由 C 的有限折线推出。
- F 与 O 分别记录 FK 支配和逐核最优性的较强读法。O 的普遍等号已被反例否定；这不影响 F，也不单凭反例断定原作者对“最优”的意图。amenable 逐核等号由既有行列式必要性与 F 合并。
- H+C 并未关闭 JO。JF 已有独立的直接构造内审通过，不能把它误记为 H+F 的自动推论；一般有序对仍须另证。
- U 须给出一个真实的共同构造。即使 JF、JO 都成立，仍须说明共同机制及各自端点条件。
- H→FUSF 编码只完成 L 的随机源接口，不完成连通修复。原题若只要求群 cost 的下确界，不能把 Bernoulli 作用上的结论偷换为同一命题。

## 连通性子节点

**L0：原图上的低度 DPP 连通捷径已被反例否定。** 在 Γ=F8×F8、G=T16□T16 上，每个 Γ 不变的 Hermitian DPP 若随机序支配 FUSF 且期望度≤2+1/64，几乎必然具有无穷多个无限分量；不要求有限依赖或核的算子序。这是所有候选的障碍，已获一份新的独立定向证明审查；只核上述定理，不认证其他旧稿全文或新颖性。故“每个群、每个原 Cayley 图、每个小预算都可选择连通 DPP”的普遍桥已否定。Lyons ICM Theorem5.10 本身没有连通性断言，仍不受影响。Q7.7 的因子表示保持输出分布，不能消除此障碍。换生成集/换图、取消 FUSF 支配、非 DPP 或长边修复均未被排除。完整论证见本目录 BRIDGE_REVIEW.md。

1. **L1：无限接触的多尺度条件引理。** 已有可复核的条件证明；须证明目标 FUSF 满足其几何假设，或寻找反例。条件引理本身不关闭 L。
2. **L2：循环空间与删边换边。** 循环缺陷公式及删边换边恒等式通过一份全文范围审查；无限度图须使用闭的稠密定义边界算子或有界局部穷竭。换边预算趋零仍等价于原 LG 目标，不能当作已证较弱引理。证据 RL01 PR #90。
3. **L3：近似与达到。** 精确达到 Betti 下界的连通图律等价于 treeability，故一般目标应保留 ε 级近似；关联边质量不逃逸与弱极限连通是独立条件。该范围已核验，不能从紧致性继承连通性。证据 RL01 PR #90。

4. **L4：交关系的小截面判据。** 有限重叠估计显示该充分判据在 F2×F2 的相应森林关系上失败；这是经一份内部审查的路线障碍，不是否定所有廉价修复。相对成本压缩及扩展下确界重新表述了剩余目标，不能计为目标已解。证据 RL01 PR #89。

5. **L5：给定乘积群森林的相关稀疏修复是标准 cost 推论。** 对 F2×F2、给定 FUSF F 和新独立正则 iid U，在输入空间(F,U)的实际自由 pmp 作用上有 fixed price 1；森林子关系 S 非周期。取任意小 S 完整截面 A，未归一化压缩公式给 C(R|A)=μ(A)，其低成本 graphing 与 S 生成整个 R。逐轨道转成边，得到每个 η>0 的全输入 Borel 等变修复，F∪Aη 连通且新增半期望度<η。允许任意长边、无 finitary 声明；完整相对输入接口已获一份独立 CORRECT，见 COST_ONE_REPAIR.md / COST_ONE_REVIEW.md。此结论源于既有 cost 理论，不能当一般 LG 新突破；此前把这个精确 benchmark 列为未解决研究目标不准确。它与 L0 不矛盾，因为修复输出不被要求仍为原图边上的 DPP。原任务 PR101 的运行结果另行收取，不追认未读内容。

## 最优阈值的构造子问题

**O1：树投影的真正最优阈值。** C3*C3 例中 FK=0，而普通支配下阈值为 1/2。分别研究该端点是否存在不变单调联合律、进一步是否有联合 iid 实现；RL01 PR #97 已给出经一份范围审查的障碍与等价有限判据：任何端点不变联合律的临界簇商森林必须处处具有无穷多个分支点；指定 rooted Wilson 联合法则不具不变性；WMSF 联合因子的二边缘分布不等于目标。各层有限LP可行等价于不变联合律存在，但全层可行性、联合iid及正次临界区间均未证。附加首层证书未纳入审查。JF 在此只给零阈值，不能代替 O1。任何 p<1/2 的结果须保留严格次临界范围。

## 相对转移子节点

**R：从已有样本出发的比较。** 对固定 K,L 和每个 η>0，已有候选证明从 X~μ_K 与独立正则 iid 产生 Y~μ_L，并满足根处差异概率≤τ|K−L|+η。完整可见核心经两份独立内审通过；未收到的稿件余文不在认证范围。其有限支撑正增量机制独立给出边缘采样 H，并以弱联合律极限给 C/D；这里弱极限只用于不变联合律，不声称仍为因子。证据 RL01 PR #94。

**R1：去除有限支撑。** 在固定 εI≤C≤D≤(1−ε)I 下，构造给定 X~μ_C 到 μ_D 的精确保序相对 iid 转移，不要求端点奇异化或变核统一可测。增量可以在群 von Neumann 代数中且有核。RL01 PR #98 的完整辅助稿经一份范围审查：单调平方穷竭下的条件扩展、任意增量的精确协变单点正流/有限期望局部活动、以及 Fourier 逼近障碍成立。一般目标仍 INCOMPLETE。秩一耦合引理归属经典投影耦合与膨胀；正流恒等式不等于独立时钟上的强构造。

**R1a：共同输入稳定性。** PR #98 的闭合定理须明确每个近似过程具有指定 DPP 边缘，以及可预测性等过程条件。末节的同一近似内振幅控制不推出跨近似的率差控制。有限三点例子给出同一精确前向方程的不同正流；另一个单点振荡率反例经独立审查，表明共同谱隙、同一近似内敏感度界、边缘一致收敛及积分前向方程收敛，仍不足以使固定泊松输入上的端点存在依概率收敛子列。须补跨指标平均率误差趋零或其他明确的同输入收敛机制，并证明各近似边缘。该反例只否定所述充分性推理，不否定端点存在性；强于端点目标的路径稳定条件不能冒充必要条件。

**R1b：有限秩一正流的维数无关选择。** 主目标仍 INCOMPLETE。PR99 的完整回复给出维数无关的有限 DPP W1/TV 界、signed divergence 修复、对角核及坐标方向两种 C=2 选择器，以及条件加权率界。一份独立审查核验这些受限核心，原稿总判 CRITICAL_GAPS：边界连续逼近遗漏、正线性障碍的固定核量词过强及来源占位符。公开整理稿补充局部修正，未计第二整稿认证。真正未闭合的是同时非负、满足出流容量、全局一致且维数无关稳定的选择器；signed 修复不够。它不证明一般 JO，也与 LG 连通桥无直接闭合关系。

**R1c：不变弱过程与强构造分层。** 对有隙线性 DPP 路径和给定协变 Borel 出生率，检验柱函数连续性方程及有限平均活动是否推出具有指定生成元的不变弱过程。独立讨论：若已有兼容的联合独立泊松表示和仅在正确边缘上的平均 Lipschitz 控制，如何严格提取强相对因子。弱存在、不变性、联合随机源、条件复制的时间兼容性及全输入等变版本分别证明；不默认互相蕴含。任务 RL01 PR #100，尚无结果。

**R2：近似与精确的分界。** 对每个 η>0分别存在转移不能代入η=0；求一系列次序违规概率趋零的联合律也不等于求可在同一输入下收敛的保序映射。一个具有固定标量DPP边缘的不变保序联合律可不是iid因子，甚至与所有 T²-遍历法则保持 d̄≥1/36；此障碍经范围审查，但同一对边缘仍可另有联合iid耦合。

## 续接规则

新材料先挂到对应节点并保全原件，再审承重步骤；结果为不完整时记录精确缺口和可复用的局部结论。新的研究任务应关闭一个节点、证明严格更弱且有用的引理，或给出反例，不重复催问已有运行任务。领域外审与查新分别记账，不能由内部审查次数代替。
