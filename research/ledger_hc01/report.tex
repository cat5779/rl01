\begin{abstract}
本文整理有限核共同移位与真实平稳 sine 熵率在高对比度区间的路线、局部正区、精确方法障碍、见证失败、未修缺口和无结果中止项。账本共登记 92 个路线单位；七库来源清单含 512 个分支、498 个 PR 和 100 个 ordinary issue。该清单量只证明来源已枚举，不再被表述为“每个结果文件内的所有子主张均已穷尽提取”。最重要的逻辑边界是：目前没有登记到高对比度真实 sine 熵率命题本身被反例否定；新增精确反例仍只否定逐项、逐词、点态、无泄漏或固定局部资源等更强主张。
\end{abstract}

\section{两个不同层次的现状}

有限核共同移位预算法已经完整写出。固定来源为
\path{papers/stationary-channel/main.tex}，文件提交
\code{16d5d55269eca9725e5eb3f5d0e6ebd785396741}，正文包含 §4 ``Bayes reallocation at the half threshold''、§5 ``Fisher--Schur closure through contrast twenty-one twenty-fifths''、§5.3 的第二个 Schur budget、张量 Bernstein 精确证书，以及 §6 向平稳情形的有限强 Jensen 传递。对比度到 $23/25$ 的定义、预算和证明是闭合的；这不等同于 $c\approx .95$ 的全参数真实 sine 熵率结果。

真实高对比度 sine 熵率目前是“远尾已付、带符号近场未付”。W02 已给
\[
  2\sum_{i<j,\,j-i>D}\mathbf E\lvert g_{ij}(\mathrm{full})\rvert
  \le nA_h(1+D)^{-\beta},
\]
证明次序是 complete posterior 的加权 Schur 行能量、统一 reveal martingale、pair 重排、求和，最后以有界 martingale 收敛与 Fatou 过有限窗极限。常数在 $c\uparrow1$ 或偏置端点退化。剩余的真实 signed near-field aggregate 没有被该远尾结果支付。

\section{本轮差异核验}

逐结果文件核验后，遗漏批评的核心部分成立：Ward--Stein、S18、QWE01、S63 O1、S67、QWE07、SA03、S42、S55、S59 的子主张确有原始结果或审查证据，现已拆成独立路线单位。三个限定必须保留：
\begin{enumerate}
  \item Ward--Stein 被否定的是逐词 $B_c(z)\le1$；Ward/Bayes/chord 恒等式、正可逆生成元和平均恒等式并未被该反例否定。
  \item QWE07 在 $\rho=.34$ 的负余量只说明旧仿射两点见证失败，不是 $H''>0$ 的反例；S59 则是局部 Bellman 子主张精确死亡而主 Gamma 路线仍无结果。
  \item S63 O1 精确否定 count-only score；它不是“计数熵可以替代完整配置熵”这一更宽主张的同义命题。计数熵、谱熵和循环直接替换三行此前只有对象区分，没有精确反例，现改为“发现缺口后未修”。
\end{enumerate}

S77 也已按原文缩窄：反例只排除固定 $\theta<1$ 加相对于 $d^2$ 为次二次的余项（$d=\lVert K_{AB}\rVert_{\rm HS}^2$）；它不排除 $\theta=1$、另一项二次资源或 sine 专用非摄动估计。S21 证据不再被 D13 重复计数；D13 只登记 QWE08 的 $-s^{10}/27$ 单项。

\section{反复出现的失败模式}

\subsection{把总平均问题强化成逐项好号}

这是出现次数最多、证据最直接的模式。S21 要求支付多项式逐系数非正，却有正的第 36 阶系数；Ward--Stein 的 32 站点证书给 $B_c=1.1776728191\ldots>1$；S18、QWE01 与 S74 分别否定两种相反方向的混合元逐项符号；S67 的 factor-one 不等式在点态和真实律平均两层都失败；SA03 也有解析负输运分量与物理坏词。与此同时，对应的共同方向 Hessian 或补偿总和仍可有正确符号。这一组证据只说明局部坏项不能被禁止，不能推出真实平均曲率为正。

\subsection{把局部或有限证书当成率结论}

S42 只支付首个 doubling，S55 的无泄漏压缩和算子范数收敛捷径都有明确反例，S67 的计数倾斜也不能与有限压缩无误差交换；S68 仍缺联合 $n$/噪声统一性，S73 缺 big-window mixed budget，SA01/QWE01 没有闭合 endpoint 和 all-size payment。W02 远尾之所以能过无限体积，是因为它保留了有限窗 martingale、统一行能量与 Fatou 的顺序；其他有限证书若缺同类接口，不能靠“尺寸更大应更好”补齐。

\subsection{换了对象却保留原结论的名字}

计数熵、谱熵、循环修正律、任意二元输入、rank-one 核线和 same-unitary 之外的 hybrid 都不是目标对象。这里必须区分“对象不同”和“已有反例”：count-only score 有 S63 O1 精确反例，而计数熵、谱熵和循环直接替换三条只定位到对象桥缺失，不能虚报成精确反例。循环模型的 $D$-sector 非正、S61 的一侧 $W_{\rm rel}$、QWE08 的 rank-one MI 和小尺寸证书仍是有效局部结论。

\subsection{值控制冒充曲率控制}

S80 的 $O(\log L/L)$ value error 没有缩弦长度平方，不能除以弦面积得到二阶结论。S42 中把大 $O$ 写成小 $o$、S78 中把约 220 倍的包络改善当成符号余量，也属于同一类“误差量纲不足”。

\section{仍缺什么}

\begin{enumerate}
  \item 固定 $c=19/20$、固定正宽度偏置 benchmark 下，真实 complete posterior 的 signed near-field aggregate 总付款；必须允许 pair/state 间抵消。
  \item 从循环/修正律回到真实 Toeplitz 输出的二阶桥、终端付款和同一近场预算。clock 的 $O(n)$ 比较与一侧 $W_{\rm rel}\ge-o(n)$ 都不是这座桥本身。
  \item $c\uparrow1$ 与偏置端点处不退化的常数，或明确避开端点的定理陈述。W02 的远尾常数只在 compact interior 内稳定。
  \item 把 S42/S80 的值级全尺度工具升级为带弦长平方的有限弦或真正二阶估计。
  \item S77/S79 的可见正文工具仍缺高秩全尺度聚合和实际 same-unitary exterior paid shell；其来源尾部可见性也应继续补齐。
  \item 对 SA01 整包仍缺覆盖性的来源审查；QWE01、QWE06 仍缺最终符号、端点或极限顺序。这里登记为“发现缺口后未修”，不是“来源缺失”。
  \item 其余六库仍需按本轮标准复扫结果正文中的子主张状态，而不能只依赖 PR 标题、摘要或顶层 verdict。当前 92 行是已核实账目，不是穷尽性完成证书。
\end{enumerate}
