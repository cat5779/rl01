# COMPUTE01：可认证数值与参数诊断

本分支认领三个需要本地计算、误差传播和参数调试的后续任务。它们补充现有
PRO01–PRO03 的理论构造任务，不与那些网页版研究任务争夺同一交付。

## 认领范围

### C01（当前执行）：SA05 的 n=8 有限符号证书

来源：`results/SA05/SA05_HANDOFF.md` 的 A 节。

固定 `c=19/20,n=8`，实现完整 70 个四元集公式并完成：

1. 少量探索搜索，定位合法有理 `a_+`,`a_-`；
2. 对 `sqrt(2)`、正七次根和对数作显式区间传播；
3. 给出 `E_8''(a_+)>0>E_8''(a_-)` 的可复核有限证书；
4. 独立判定中点 `a_*=1/40` 的有限 `E_8''` 符号；
5. 用 256 个完整原子做归一、层权重与 Hessian 差的交叉核查。

这只认证所列有限参数点，不外推到全 `n`、渐近符号或熵率。

### C02（已认领，C01 后执行）：SA04 中央层尺度诊断

来源：`results/SA04/COMPUTATION_HANDOFF.md`。

利用最大重叠初值对固定 `A` 的对称性，把热流降到一维出生死亡链，分别计算
`A_l,E_l,d_l=A_l-E_l,w_l` 和完整加权和 `W_n`。保留实际原始时钟，禁止把
`E_l` 与任务的 `C_n` 混同。输出高精度误差预算与中央窗口缩放诊断，用来区分：

- `d_l=O(n^{-1/2})`；
- 非零常数尺度；
- `A_l,E_l` 单独为常数但发生更强抵消。

有限拟合只用于选择下一条待证引理，不标成渐近定理。本项严格
`CORRECTED_LAW_ONLY`。

### C03（已认领，较低优先级）：SA03 局部残差与截断证书框架

来源：`results/SA03/COMPUTATION_HANDOFF.md`。

对真实 Fejer Toeplitz word 律计算四项局部残差及总和，先建立小 `R` 的高精度
诊断和原始 jets 回归，再接入显式空间尾与 `u` 积分误差。目标是产生一个可认证
有限表示或明确指出现有常数离判定 `Gamma(19/20)` 还有多大差距。

本项不把有限 `R` 正性、浮点拟合或弱耦合级数冒充 `Gamma(19/20)` 的符号证明。

## 证据等级

- `EXPLORATORY`：浮点或高精度诊断，只能定位候选。
- `FINITE_CERTIFIED`：输入、区间传播和最终符号均可复核，只认证所列有限实例。
- `GENERAL_PROVED`：必须另有对全部量词有效的解析证明；本分支默认不作此声明。
- `INCOMPLETE`：程序或误差预算尚不能决定目标。

任何输出都必须记录真实概率权重、完整二阶导数、移动参考/层权重以及误差传播。
不使用哈希清单作为数学验收，也不重跑与当前判别无关的旧证书。

## 运行

当前 C01 探索程序只用 Python 标准库：

```text
python research/COMPUTE01/sa05_n8_explore.py
```

它使用二阶自动微分而不是有限差分，并检查 70 状态数据的零质量关系。输出仍是
`EXPLORATORY`；后续区间版会单独生成 `FINITE_CERTIFIED` 收据。

首轮结果见 `sa05_n8_explore_result.json`。二阶自动微分发现简单候选
`a_-=1/200` 与 `a_+=1/50`，并给出中点正号。随后
`sa05_n8_interval.py` 使用整数与 `Fraction` 完成 96-bit 有理向外区间传播；三个
符号已认证，见 `SA05_N8_CERTIFICATE.md` 和 `sa05_n8_interval_result.json`。
`sa05_n8_full_atoms.py` 又从 Fourier 投影的 4x4 主子式、潜在 DPP 与逐坐标信道
独立重建全部 256 个输出原子，并把完整熵 Hessian 与 70 状态表达式逐项核对。
该回归使用 binary64，不承担符号认证；严格符号仍只来自有理区间程序。

C02 的首轮程序 `sa04_central_scale.py` 已完成固定潜在集合的一维出生死亡链降维，
并通过 DPP 交叠计数生成函数恢复混合律。`n=6,8,...,20` 的结果和验算见
`SA04_CENTRAL_SCALE.md`；它们支持把“中央 `d_l` 非消失”作为下一条待证方向，
但仍明确标为有限 binary64 探索结果。
