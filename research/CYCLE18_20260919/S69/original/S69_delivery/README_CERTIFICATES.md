# S69 certificate sources

This directory accompanies `RESULT.md`.  It proves the enlarged interval

`K = [1/50, 51/2000] = [0.02, 0.0255]`

for `rho=1/3`, `c=19/20`, and proves the score-matched obstruction at
`a=13/500=0.026` for the same 22-site nearest-neighbour architecture.

## Arithmetic model

The C++ interval programs require an x86-style binary `long double` with a
64-bit significand.  `cert_interval.hpp` checks this at compile time.  Every
elementary endpoint is pushed outward by one adjacent representable number;
compile with

```
-O3 -frounding-math -ffp-contract=off -std=c++17
```

and add `-fopenmp` for the OpenMP programs.  The principal-probability
enumerator uses checked, fixed-width Boost multiprecision integers with 192
fractional bits; overflow is an error.

The exact Python closers use only the standard library (`fractions`,
`decimal`, `math`, and `pathlib`).

## Exact inputs

- `alpha60.txt`: 60-place rational bracket for `sqrt(3)/(2*pi)`.
- `guard_caps_integer.txt`: all 256 `(L_z,U_z)` guard pairs.
- `payment_coefficients_s69_integer.txt`: published degree-eight payment
  coefficient boxes, denominator `10^8`.
- `bernstein_payment_s69.txt`: complete exact Bernstein coefficient lists.

## Main theorem programs

- `global_ratio_certificate_s69.cpp`: global scalar pair cap on all of `K`.
- `guard_certificate_s69.cpp`: guarded posterior continuum verifier.
- `principal_probability_certificate.cpp`: complete 22-site law at `a=1/40`.
- `payment_prepare_s69.cpp`: constructs the affine local potentials `V0,V1`.
- `payment_step_s69.cpp`: checkpointed nilpotent derivative/expectation steps.
- `payment_extract_integer_s69.cpp`: converts each outward expectation sum
  directly to integer lower/upper enclosures with denominator `10^15`.
- `assemble_payment_coefficients_s69.py`: combines those integer enclosures
  by exact rational arithmetic and adds one publication unit of `10^-8` on
  each side.
- `verify_rational_s69.py`: exact alpha, tail, payment, Bernstein, PSD, and
  `M=19` closure.
- `check_guard_logs.py`: checks word/cell coverage of guard logs.

The reported run imported the already accepted S63 guard cells on
`[0.021,0.024]` and freshly verified the five added cells.  The supplied
rerun script instead recomputes all eleven cells, so it is self-contained.

## Obstruction programs

- `guard_probe_026_tight.cpp`: all 256 guard words on that probe interval.
- `verify_tight_probe_026.py`: exact PSD check for the probe allocation.
- `principal_probability_certificate_026.cpp`: complete 22-site law at
  `a=0.026`.
- `score_ceiling_026_tight.cpp`: outward score-matched maximum and negative
  payment gap.
- `verify_failure_audit_s69.py`: exact audit of the old fixed witness at
  `a=0.02` and `a=0.026`.

## Full rerun

Run from this directory:

```
THREADS=8 ./run_from_scratch.sh
```

The script compiles sources, reruns every continuum guard cell, regenerates
all 4,194,304-word probability caches at both anchors, performs the
checkpointed payment calculation, and executes both exact rational closers.
It uses substantial disk space while running because interval vectors store
two `long double` endpoints per word.
