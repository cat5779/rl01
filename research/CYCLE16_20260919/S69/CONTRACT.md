# Research contract
Think for at least 120 minutes, unless you achieve major progress earlier.
A qualifying early finish is a proved, internally checked advance that materially enlarges an accepted parameter region or closes a real load-bearing obligation. Renaming a remainder, reproducing an identity, or observing a few signs is not enough. Never invent duration or idle to fill time; if interrupted, preserve a resumable proof checkpoint.
Do not route the user to Work; this is a mathematical derivation task.

Create and test a reusable mathematical tool, not merely a survey or a restatement of the target. Write its required properties first (actual-law compatibility, correct derivative order, normalization, scaling, and quantitative payment), construct it, and prove its interface to this task. Consider transferable ideas outside DPP theory: conditional-expectation geometry, variational duality, robust optimization, interpolation, information inequalities, or another justified mechanism. A direct complete proof takes priority over this heuristic. Theory is central; there is no computation cap or mandatory heavy-computation handoff.

All entropy is full spatial-configuration Shannon entropy in natural units. Keep actual weights, moving reference derivatives, all words including rare ones, and boundary/leakage terms. Finite Toeplitz compression is not a projection. Count entropy, spectral trace entropy, corrected cyclic entropy and true configuration entropy are not interchangeable. A value o(n) error cannot be differentiated for free. Small-volume or finite-grid evidence is not an asymptotic theorem or continuum certificate.

Work independently on this task. Do not launch agents, contact other researchers, merge PRs, or modify shared status. A file-only agent needs no network or repository write access: PACKET.md embeds every supplied text/source attachment. If browsing is available, use original papers for outside results; inaccessible sources are not assumed. This packet's current status overrides historical status paragraphs in old attachments.

No SHA/checksum/hash acceptance gates. A broken ZIP or missing manifest does not invalidate completed mathematics. Deliver readable proof and source files even if export fails. Preserve original sources separately from your changes.
Return a self-contained English RESULT.md with exact theorem/obstruction and PROVED, DISPROVED or INCOMPLETE; complete proofs; dependency/scope ledger; falsification attempts; reproducible evidence where used; and the smallest remaining inequality if incomplete. Include code and exact inputs for every computational certificate; successful log messages alone are not a proof. A counterexample to an intermediate claim is not a counterexample to entropy-rate concavity.
