# QWE07 submission — density extension, PR129

## Proven result

For the actual sine-kernel configuration entropy, c=19/20,
rho in [1/3,1009/3000], a in [21/1000,3/125], and every integer n>=22:

    H_{rho,n}''(a) <= -n/25 + 399.

The stationary entropy-rate chord coefficient is 1/50 in a, or 1/20000
in p=20a. This is a computer-assisted continuum theorem, not a density grid claim.
Half density and the global concavity conjecture are not proved.

`RESULT.md` contains the complete mathematical argument, exact theorem,
all guard and nodal integers, dependency/scope ledger, falsification attempts,
and the precise obstruction for reusing the unchanged witness outside the band.

## Reproduction

From `certificates/`, run:

    bash run_certificates.sh

Requirements: x86-64 with binary long double having 64 significand bits,
C++17 GCC (the completed runs used 14.2.0), OpenMP, Boost headers for the
arithmetic self-test, and Python 3's standard library (tested with 3.13.5).
Do not enable fast-math, reassociation, or floating contraction.
The whole-word calculation creates a local roughly 256 MiB test-potential cache;
it is always regenerated by the script before use. Compiled artifacts and
fresh logs are local reproduction products, not supplied proof inputs.

For an audit of only the supplied exact arithmetic and coverage records:

    python3 verify_density.py
    python3 check_guard_coverage.py guard_final.log
    python3 collect_nodes.py witness_nodes.log /tmp/qwe07_nodes_integer.txt
    python3 verify_probes.py

This lighter audit does not rerun the interval matrix/whole-word calculations.
The script `run_certificates.sh` reruns those computations as well.
