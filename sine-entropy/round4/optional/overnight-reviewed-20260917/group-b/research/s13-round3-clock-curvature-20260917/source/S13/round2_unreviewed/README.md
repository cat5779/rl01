# S13 continuation — round two

## What is proved

`proof.md` proves two new scoped theorems for the genuine contiguous cyclic
Fourier family at density `1/2`.

1. The exact potential-transfer defect, with the actual moving count law and
   exact true/surrogate conditional laws, is logarithmic in value and has an
   explicit negative `sqrt(n) log n` curvature boundary layer at the symmetric
   shift.
2. A positive deterministic Bernoulli--Laplace potential-clock law exactly
   matches the potential-relevant degree-two mode on every layer.  Its entropy
   value is within `O(log n)` of the mean-clock surrogate and
   `O(sqrt(n) log n)` of the actual law on compact interiors.  These value
   estimates are not differentiated.
3. Positive random forward-time mixtures of the original BL chain cannot match
   both the actual degree-one and degree-two multipliers on growing central
   layers.  This is a precise class no-go, not a universal transport no-go.

## What is not proved

The sine entropy-rate target remains open.  The corrected law's complete
Fourier-reference KL/moving-layer signed Jensen budget is not controlled.  In
particular, no sign is claimed for `Dhat_F''`, which includes conditional
acceleration, conditional Fisher, `2 pi_l' Dhat_l'`, and
`pi_l'' Dhat_l`.
