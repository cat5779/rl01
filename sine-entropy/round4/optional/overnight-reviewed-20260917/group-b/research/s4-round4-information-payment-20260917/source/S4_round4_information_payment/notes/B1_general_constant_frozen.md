# B1 general-contrast extension to check

The factor-2 statement remains the principal explicit region claim. Also test/prove the same bounds with factor
  kappa(a,c)=min{ [1-c^4]^-1/2, theta/(1-exp(-theta)), 2 if c^2<=23/25 },
  theta=log[(a+c)(1-a)/(a(1-a-c))].
All factors are >=1. The first term follows if the scalar ratio log odds/(d sum 1/p) is at most 1/(2 sqrt(s0(1-s0))) for s0=(1-c^2)/2. The second uses the actual channel logit range. These are scalar log-mean estimates to be proved, not external curvature hypotheses.

Then I'' <= kappa Psi, J_T'' <= I'', and the residual time/rank bound has kappa in place of 2. For fixed c this is O(delta^-2), compared with the prior author theorem's delta^-5 times input entropy. No assertion is made that the local instantaneous Q_t'' has this sharper bound.
