1. 核对 PR118 六份原提示、当前审核索引及 S4/S7/S9/S13 的适用范围。
2. 分清 S13 修正律和真实输出律；单独建立桥接任务，防止把修正模型的正项直接挪给真实熵。
3. 提供完整计数运输、移动参考和条件揭示恒等式，见 [公共起点](COMMON_STARTER.md)。它们是直接代数输入，不作为新定理宣传，也不算 Pro 的新贡献。
4. 补写并实际运行纯 Python 标准库检查器，恢复旧 S7 审核因源码缺失而未复现的六点证书：真实 sine 核下 `0.00037 < E g_(1,6) < 0.00039`，同时 `-50 < H_6'' < -49`。采用有理多项式和有理向外区间，不用浮点数判定符号。见 [检查说明](checks/README.md) 和 [结果](checks/seed_results.json)。

这些工作使每题有可检查的起点；全局高对比度 sine 熵率凹性仍然开放。

## 减负但不降低数学真实性

取消固定思考分钟数、八候选配额、三次失败配额、单题必须统一两条残差、必须只剩一个缺口，以及先证明一致尺度才能开始研究的门槛。保留真实配置律、完整二阶导数、符号抵消和适用范围。

本包不要求生成、更新或通过任何哈希清单。历史仓库的清单与旧脚本不属于本次任务的验收步骤。数学完成度由证明、反例和可复核的具体结果判断；仓库访问、脚本执行、压缩包或上传故障须单列，不能覆盖已完成的数学成果。没有工具时直接交付完整正文及可复制代码。

先分别评审每题的命题、证明及反例；不按赞成票数判真。01–03 的真实律结果各自保留作用域。04 只能记作修正模型结果；05 只有提供方向正确且尺度相容的比较后，才能与04合用。循环投影、Toeplitz 压缩和熵率之间的传递另列义务。最后才判断是否出现一个共同工具或新的参数区域，不能提前要求五题凑成统一定理。
