# 小型数学检查器

任意 Python 3，标准库即可：

```text
python checks/check_seed.py
```

从本包根目录运行。写出 `checks/seed_results.json`。没有安装、联网、仓库登录、完整性清单或全库测试前提。无法执行时仍可读源码与公式、交付正文，不把执行故障算数学失败。

本次已实际执行成功：

- 半密度真实 sine Toeplitz 六点压缩，`c=19/20,a=1/40`；枚举全部64个完整原子。
- 原子是 `t=(c/pi)^2` 的有理多项式；精确验证归一化。
- Machin 公式及交错 arctan 余项围住 pi；正 atanh 级数及尾界围住 log；每次区间运算向外舍入到 `10^-40` 网格。
- 有理区间严格证明 `37/100000 < E g_(1,6) < 39/100000` 与 `-50<H_6''<-49`；并核对完整 pair/对角 Hessian 分解。
- 精确有理检查一个非恒定、随 a 移动的层测试函数，比较直接权重微分与计数运输表达式。

显示小数仅用于阅读；判定使用分数端点。两种 Hessian 表达式之差的区间包含0是相容性检查，不独立构成恒等式证明；一般恒等式来自明确的有限概率推导。检查恢复的是已有六点例子的独立证书，不声称新发现此例，也不证明全局凹性。计数检查验证接口实现，不证明实际空间 KL 的符号。
