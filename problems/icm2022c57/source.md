# ICM source and numbering

Primary source:

Richard Evan Schwartz, “Survey lecture on billiards,” *Proceedings of the International Congress of Mathematicians 2022*, Vol. 4, pp. 2392–2429, DOI [10.4171/ICM2022/66](https://doi.org/10.4171/ICM2022/66). [EMS article PDF](https://ems.press/content/book-chapter-files/33207).

In Section 5.3, the article defines a stable periodic billiard path as one whose combinatorial type persists on all nearby triangles. For a stable finite word \(w\), it defines \(O(w)\) as the set of triangle parameters supporting a periodic path with sequence \(w\), calls this set the orbit tile, and explains via unfolding that its boundary is governed by finitely many trigonometric equalities. On p. 2407 it then states formally:

> **Conjecture 5.7.** Orbit tiles are connected and simply connected.

The angle-simplex presentation in `problem.md` is a nonredundant coordinate model of the same labeled-triangle parameter space used by Schwartz. It preserves the source's complete orbit tile, rather than restricting to a numerical plot or to one component.
