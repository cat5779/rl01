# 正弦 DPP 熵率研究：当前进展与接手入口

更新：2026-09-20，交接轮 Cycle34。**主猜想仍开放；整个 c∈(0.925,1) 尚未解决，也没有实际 sine 熵率的反例。**

研究对象是 K_n(a)=aI+cQ_{rho,n} 的全部空间配置 Shannon 熵率，Q 是正弦 Toeplitz 压缩。最终要求每个固定0<rho,c<1、全部合法a上凹。准确量词见 TARGET.md；有限弦差证明也可完成目标，不要求先证明熵率可二次微分。

## 已经推进到哪里

通用、全密度、全合法偏置基线仍是 c<=37/40。超过此阈值，已有真实熵率的局部区域：rho=1/3、c=.95 的非中点区间，并分别向密度和c扩展。其中一条覆盖 c∈[.95,.9535]、a=(1-c)p、p∈[.42,.48]。这些区域不能拼成尚未证明的参数笛卡尔积。精确范围见 STATUS.md。

| 路线 | 已独审成果 | 真正剩余问题 |
|---|---|---|
| 真实区块互信息：S77、QWE08 | Fisher–Burg精确抵消；秩一二部核任意切割凸性；四格点以内连续偏置证书 | 任意尺寸的负环项／Burg项如何由正项整体控制 |
| 实际揭示：S75、S78 | 单中心星形正漂移；多中心秩一logdet补偿；误差包络约缩小220倍 | 核心截断仍约486.93，逐对累加仍可能为二次规模 |
| 奇偶／循环：S76、S79 | D项全尺寸中点非正；second-chaos与shell公式；跨层删除一致性 | C_X或shell相对熵曲率未付；真实率桥、非中点、一般密度另需证明 |

S80完整原稿已收，提出准自由互信息主控的全尺度Jensen弦差残差和行列式相互作用估计，**已由RL01 PR71独审通过其限定结论**。作者也承认：残差不含弦长平方因子，不能据此推出局部或全区间凹性。不要把“全尺度求和有界”当成“足以支付曲率”。
